# Contributing

Issues and pull requests are welcome. Oboecraft is a small project kept up in spare time, so replies can take a while.

## Before you start

- For anything bigger than a small fix, open an issue first, so we can agree on the idea before you spend time on it.
- [`AGENTS.md`](AGENTS.md) has the commands to build and test the mod and the project's rules for branches, commits, pull requests, tests and docs. They apply to people and coding agents alike.
- `./gradlew build` passes before a pull request is opened.

## Licenses of contributions

A contribution is under the same license as the files it changes or adds to: code under the [MIT license](LICENSE), and the name list's readings under CC BY-SA 4.0, as [`CREDITS.md`](CREDITS.md) says. There is no contributor license agreement. By opening a pull request, you confirm that you have the right to contribute its contents under those terms.

New assets, like sounds, textures or data, need terms that allow them to ship in the published mod and to be redistributed by anyone who forks it. Add their source, license and what was changed to `CREDITS.md` in the same pull request.

## Security

Report security issues privately through the repository's Security tab ("Report a vulnerability"), not in a public issue.
