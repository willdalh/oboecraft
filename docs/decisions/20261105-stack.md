# ADR-20261105: Fabric, Java 25 and only the latest Minecraft version

## Status
Accepted

## Context
Before any code is written, Oboecraft needs a mod loader, a language and a Minecraft version to target. The project is new to Minecraft modding, so the stack needs good beginner docs and should keep up with new Minecraft versions. Players should need as few other mods as possible to run it.

## Decision
- Mod loader: Fabric.
- Language: Java 25, the version Minecraft 26.3 needs.
- Minecraft version: only the latest, 26.3 at the time of writing. The mod moves to each new version once Fabric supports it.
- Fabric API is the only required dependency. Settings are stored in our own JSON files and edited in our own settings screen. Mod Menu is supported as an optional dependency that opens this screen.

Alternatives considered:
- NeoForge. Fabric was picked because it has the most mods for current versions, is usually first to update, and has good beginner docs.
- Kotlin. Every player would have to install an extra language mod.
- Supporting several Minecraft versions at once. More code paths and testing for one person to maintain.
- Config libraries like YACL or Cloth Config. They would save writing a settings screen, but every player would have to install another mod.

## Consequences
- Players on older Minecraft versions can't use the mod.
- Each new Minecraft version needs an update, done once Fabric supports it.
- NeoForge can be added later as another adapter module, without touching `core`.
- Since 26.1, Minecraft ships unobfuscated, so the code uses Mojang's names and Fabric Loom's non-remapping plugin.
- We write and maintain our own settings screen and settings files.
